## Security/privacy scope and operational limitations

- Source archives are user provided, never arbitrary HTTP-fetched. 160KB total per artifact, 30 artifacts per case. PDF extraction uses `pypdf` in process, without independent exploit-resistant sandbox assurance. Binary data are stored as base64 in database and can be retrieved only by authorized case analysts. Original-download route uses attachment plus nosniff; expiration blocks downloading but expiry purging requires explicit action, and database backups may retain copies.
- Image/screenshot names do not establish a pictured person. Linked source records never establish source ownership, employer or student status, person identity, wrongdoing or truth automatically.
- Additive tables: `evidence_source_reviews`, `claim_conflict_reviews`, `source_document_archives`, `source_link_checks`. These use `CREATE TABLE IF NOT EXISTS` startup initialization. **No versioned production migration or verified PostgreSQL restore has occurred.**
- Vercel frontend last known blocking issue: deployment free daily quota and outdated production frontend; check quota and release parity after main merge. Do not claim production frontend parity without confirming the exact SHA.
- Render free PostgreSQL expiry previously observed for **2026-11-23**; owner approval and documented restore test still needed. No plan change or database allowlist weakening.
- No live Groq/Brave calls or legal/client approval in CI. Real-world identity precision, source rights and claim authenticity remain open.
