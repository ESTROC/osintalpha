# OSINT Alpha V7.7 — Attributable candidate portfolio and coarse public map

## Included in this branch

- Case-scoped public portfolio endpoint: candidates remain independent, each with original source URL, retrieval time, source provider, review status, organization, published location, and public handle where available.
- GitHub public avatar and website metadata retained for display; the image is the candidate account's own avatar, not confirmed photo identification of the investigated person.
- OpenAlex persistent ORCID identifier included in the stored source metadata if published.
- Brave web discovery now prioritizes site-scoped LinkedIn professional URLs, GitHub and published portfolio pages; these are search snippets until reviewed, not LinkedIn API enrichment or verified profiles.
- Portfolio tab in the analyst console, source inspection links, responsive cards, and a voluntary city-only Leaflet map.
- Map requests transmit only an analyst-supplied city/region clue to OpenStreetMap Nominatim after an explicit analyst action. Requests are cached and throttled; coarse place centroid is returned, not private, current or residential location.
- Synthetic tests cover duplicate namesake candidates, avatar allowlisting, consent, address rejection, bounded search plans and a mocked map lookup.

## Provider setup

BRAVE_SEARCH_API_KEY is an optional secret to configure privately in Render. No API keys are generated by this repository and the frontend never receives the secret.

Brave search requires a valid provider account, enough credits and explicit case-level external search consent. No LinkedIn public person-search credential offers unrestricted lawfully scrapeable professional records. TfL camera credentials have no relevance to person-search accuracy.

## Known limitations and release gates

This is not a completed or independently verified identity resolver. Public LinkedIn result snippets and GitHub profile photos are not evidence of identity. Site query results can be stale or wrong. Place names can be ambiguous; map preview displays only an approximate analyst clue.

External OpenStreetMap tile/geocoding policies and publisher image licenses must be followed; use paid or self-hosted services at production scale.

Live-provider verification, calibrated identity ground truth, certified photo matching, educational/employer confirmation, claim entailment, Playwright browser testing, tested backups/restore, privacy/security review, and exact original 95-issue acceptance remain pending.
