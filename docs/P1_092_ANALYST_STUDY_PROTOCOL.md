# P1-092 — target analyst usability study protocol (NOT conducted)

**Status:** Protocol prepared; no real participants, scores, permissions or feedback collected. Never claim independent investigator acceptance from mock tests.

Purpose: Observe 5–10 authorized agency analysts using only synthetic names, organizations and generated public-source evidence. Do not ask for operational cases, sensitive personal identifiers, passwords or real targets.

Consent: Written opt-in and purpose; voluntary discontinuation; no secret-screen recordings; capture task timings, functional obstacles and approved comments only. Allow anonymous role labels and delete notes on request, subject to agreed policy.

Tasks (counterbalanced): (1) clarify two same-name candidate profiles, (2) identify which search adapter failed, (3) find an original source and an exact quotation, (4) record counterevidence, (5) generate and inspect reviewed draft, (6) resume an interrupted investigation, (7) locate quotas/health status. On mobile repeat tasks 1–3.

Measures: elapsed seconds and completion status per task, number of wrong candidate merges/unsupported identity statements (zero tolerance), 1–5 task difficulty, successful keyboard navigation, whether analyst correctly distinguishes search lead/corroborated/verified fact. Record failure severity, steps to reproduce, and user quote only with consent.

Acceptance criteria proposed for signoff (not yet attained): >=8 of 10 timed participants finish core tasks without assistance; no case-mixing or disclosure errors; 100% see uncertainty and provider-failure caveats; fewer than 2 critical confusion defects; security/legal approval separate.

Artifacts to retain with participant authorization: aggregate timings, accessibility defect list, usability backlog, evidence of fixes, signed product-owner review. Without participants, item 092 remains BLOCKED_EXTERNAL.
