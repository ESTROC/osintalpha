## Regression changes

New Python tests in `tests/test_p1_089_refinement.py`, `test_p1_090_reviewed_report.py`, `test_p1_094_095_096_provider_ops.py`, `test_p1_095_provider_backoff.py`, `test_p1_097_pdf_process.py`, `test_p1_098_login_db_limit.py`, `test_p1_091_case_link_restore.py`, plus real browser `test_browser_acceptance.py`.

Tests are synthetic and verify safety/contract behavior. Live source correctness, independent identity accuracy, model response quality and legal source ownership are not measured. No third-party secrets or real targeted private-person records used.

## Release controls and known blockers

- Merge to main only when **exact PR head** Python tests, JS smoke and real Chromium browser CI are green; run main CI and verify Render backend LIVE plus Vercel frontend READY on exact merged SHA.
- New additive DB schema: `auth_failed_attempts`, `candidate_refinements`, `external_api_call_ledger`, `external_api_daily_counters`, `provider_health_events`. PostgreSQL schema initializes via `CREATE TABLE IF NOT EXISTS`; **no witnessed production backup or isolated restore**.
- Per-case limits are atomic daily counters. Limits do not equal actual provider quotas or monetary charges.
- Historical Render PostgreSQL free-plan expiry **2026-11-23**, no approved paid upgrade, backup/restore or secure data retention audit; deployment alone does not resolve data-loss risk.
- Browser tests do not amount to a human analyst usability study; signatures and source URLs do not establish legal identity or claim truth.
